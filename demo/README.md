# vue-parley demo

A playground for the package, on the in-memory fake backend (`vue-parley/fakes`).

```sh
pnpm demo   # from the repo root: builds the package, then starts the demo
```

- Language (fa/en, RTL/LTR) and dark mode switch from the top bar.
- Calls: use "Open as …" for a second tab with another user, then call from either tab. Screen share is on.
- Host extension points: a header action, a header menu option, a "Pin" message option and an `above-input` notice.
